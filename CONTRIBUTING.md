
# Contributing Guidelines

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

We appreciate your interest in improving this project. Every contribution helps make the Simple Interest Calculator better.

## How to Contribute

1. Fork this repository.
2. Create a new branch for your changes.
3. Make your improvements or bug fixes.
4. Test your changes.
5. Submit a Pull Request with a clear description of your contribution.

## Reporting Bugs

If you find a bug, please open an issue and provide:
- A clear description of the problem.
- Steps to reproduce the issue.
- Expected and actual results.

## Suggesting Enhancements

You are welcome to suggest new features, improvements, and ideas through GitHub Issues.

## Code of Conduct

All contributors are expected to follow the project's Code of Conduct.

Thank you for contributing!
