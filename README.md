
# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is a simple project that calculates the interest earned or payable on a principal amount over a specified period at a given annual interest rate.

## Formula
Simple Interest (SI) = (P × R × T) / 100

Where:
- P = Principal Amount
- R = Annual Rate of Interest
- T = Time Period (in years)

## Example
Suppose:
- Principal Amount = ₹10,000
- Rate of Interest = 5%
- Time = 2 Years

Calculation:

SI = (10000 × 5 × 2) / 100

Simple Interest = ₹1,000

Total Amount = ₹11,000

## Features
- Accepts principal amount.
- Accepts annual interest rate.
- Accepts time period in years.
- Calculates simple interest.
- Displays the total amount.
